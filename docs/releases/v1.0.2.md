Computational materials accompanying *Quantile spectral regression and simultaneous inference for repeated EEG recordings*, by Tianbo Chen and Hanbing Zhu.

This version contains the manuscript theory and proofs for varying segment counts and lengths, conditional inference for balanced exposure allocation, the N=40 null simulations, and four calibration settings based on the 22-subject paired EEG design. It includes clarified finite-bootstrap inference, consistent terminology, and the labeled log quantile spectral contrasts.

Download **QSEEG_code.zip** for the complete computational materials. It contains the programs, manuscript components, metadata, sleep-stage annotations, derived spectral features for 197 recordings, simulation records, and EEG results. The bundle directly reproduces the paper without combining separate archives.
