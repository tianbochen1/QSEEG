# QSEEG v1.0.5

The computational bundle accompanies *Quantile spectral regression and simultaneous inference for repeated EEG recordings* by Tianbo Chen and Hanbing Zhu.

Quantile and ordinary regression now share an eligibility check at each channel and window length. A segment contributes only if every rank indicator on the analysis grid has positive variance. The included tests cover ties, mixed eligibility across window lengths and channels, earlier feature archives, and loss of a paired night.

Table A2 reports simultaneous coverage of the zero exposure curve in the 40-subject volatility experiments. The four entries follow directly from the retained Monte Carlo records. All 52 EEG fits were recomputed with the updated eligibility check. The included segments, estimates, standard errors, and bootstrap distributions match the previous results.

The complete archive contains the analysis code, manuscript components, source metadata and annotations, derived EEG features, and numerical results. Download QSEEG_code.zip and follow its README to reproduce the tables, figures, and manuscript.
