Computational materials accompanying *Quantile spectral regression and simultaneous inference for repeated EEG recordings*, by Tianbo Chen and Hanbing Zhu.

The manuscript specifies the finite-resolution regression target, nested night and segment weights, the Gaussian comparison statistic, and the residual-vector covariance in the paired-design calibration, including subject-specific scales. It also defines the segment timing covariate and separates bootstrap order-statistic notation from the sampling rate. Numerical results and analysis settings are unchanged.

Download **QSEEG_code.zip** for the complete computational materials. It contains the programs, manuscript components, metadata, sleep-stage annotations, derived spectral features for 197 recordings, simulation records, and EEG results. The bundle reproduces the paper without combining separate archives.
